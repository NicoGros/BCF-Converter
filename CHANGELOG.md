# Changelog

All notable changes to this project will be documented in this file.

## [1.0.1] - 2026-08-25

### Changed

- Updated application version metadata to 1.0.1.
- Uploaded the code to GitHub
- Added application logo

## [1.0.0]

### Added

- BCF file loading.
- Spectral cube extraction using HyperSpy.
- Preview of a selected spectral region.
- Conversion of BCF spectral cubes to HDF5.
- Preservation of basic spectral axis metadata.
- Gzip compression of output HDF5 datasets.
- Windows standalone executable.
