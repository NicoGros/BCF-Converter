# Contributing to BCF Converter

Thank you for your interest in improving BCF Converter.

BCF Converter is a Python desktop application for converting Bruker BCF spectral data to HDF5 format.
Other file formats were not included because I had no use of it, but it could be added easily.

## Reporting issues

Please use the GitHub issue tracker.

When reporting a bug, include:

- BCF Converter version.
- Operating system and version.
- Python version, if running from source.
- A description of the BCF file involved, including its origin and acquisition software/version where relevant.
- Steps to reproduce the problem.
- The error message, if applicable.
- Screenshots if relevant.

Please do not upload confidential or otherwise restricted scientific data to public issues.
